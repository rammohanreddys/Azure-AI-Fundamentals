# Generative AI Concepts:

## What is generative AI?

Artificial Intelligence (AI) imitates human behavior by using machine learning to interact with the environment and execute tasks without explicit directions on what to output.

Generative AI describes a category of capabilities within AI that create original content. These capabilities include taking in natural language input, and returning appropriate responses in a variety of formats such as natural language, images, code, and more. Let's take a look at a couple of examples:

### Large Language Models (LLMs):

* Based on Transformer architecture.
* Trained on massive text datasets.
* Can perform text generation, summarization, translation, reasoning, etc.
* **Examples:**
  * OpenAI’s GPT series
  * Google’s PaLM
  * Meta’s LLaMA
  * Anthropic’s Claude


### Key Concepts:

1. **Prompting**:

  * You give the model a prompt (e.g., "Write a poem about the moon") and it generates a response.
  * Foundation for applications like ChatGPT.

2. **Fine-tuning**:

  * Adjusting a pre-trained model on a specific dataset or task (e.g., legal documents, medical notes).

3. **Few-shot / Zero-shot / One-shot Learning**:

  * The ability of a model to perform tasks with little or no task-specific training by learning from examples in the prompt.

| Term          | Meaning                                     |
| ------------- | ------------------------------------------- |
| **Zero-shot** | Performs a task without seeing examples     |
| **One-shot**  | Learns from one example                     |
| **Few-shot**  | Learns from a few examples (2–10 typically) |


4. **Diffusion Models**:

  * Used for image and video generation (e.g., DALL·E 3, Midjourney, Stable Diffusion).
  * Work by gradually denoising a random signal into a meaningful output.

5. **Ethical & Practical Considerations**:

| Topic              | Description                                                           |
| ------------------ | --------------------------------------------------------------------- |
| **Bias**           | Generative models can reproduce or amplify social biases              |
| **Misinformation** | Can generate believable fake news, deepfakes                          |
| **Plagiarism/IP**  | Risk of copying training data (e.g., artists' work, proprietary code) |
| **Hallucination**  | Models can generate **confident but incorrect** answers               |
| **Security**       | Prompt injection, jailbreaking, model leakage are real risks          |

6. **Popular Applications**:

  * **Text:** Chatbots, writing assistants, summarization tools
  * **Image:** AI art, product design, fashion
  * **Video:** Synthetic avatars, video editing
  * **Audio:** Music generation, voice cloning
  * **Code:** Code generation, auto-completion (e.g., GitHub Copilot)
  * **Synthetic Data:** For training AI without using sensitive real data

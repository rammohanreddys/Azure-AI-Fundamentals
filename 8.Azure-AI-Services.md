# Azure-AI-Services:

Azure AI Services (earlier called **Azure Cognitive Services**) are a set of pre-built, cloud-based AI APIs and tools provided by Microsoft Azure.

They allow developers to add AI capabilities to applications without needing deep expertise in ML or data science.

These services are grouped into different categories, each designed for specific AI workloads.

## Categories of Azure AI Services & Workloads:

1. Vision (Computer Vision Workloads)
2. Speech (Speech AI Workloads)
3. Language (NLP Workloads)
4. Decision (AI-driven Decision Workloads)
5. Search & Knowledge Mining
6. Machine Learning workloads
7. Generative AI / Consersational AI

## 5. Search & Knowledge Mining:

The Search & Knowledge Mining workload in Azure AI is centered around Azure AI Search (formerly Azure Cognitive Search). This fully managed service is designed to make all your content—structured and unstructured—searchable and discoverable by combining traditional full-text search with advanced AI-driven techniques.

### 2. Knowledge Mining: The Three Phases:

Knowledge Mining is the process of using AI to ingest, enrich, and explore insights from vast amounts of heterogenous data (documents, images, databases). Azure AI Search is the orchestrator of this process:

**Phase 1: Ingest**

Content is pulled into the service from various sources using Indexers.

**Data Sources:** Connectors are available for services like Azure Blob Storage, Azure Cosmos DB, Azure SQL Database, and SharePoint.
**Indexing Pipeline:** The indexer reads the source content, extracts text (even from formats like PDFs, Word documents, and images), and prepares it for the next phase.

**Phase 2: Enrich**

This is where the "AI" component of the workload comes in, using Skillsets to apply intelligence to the content.

* **Cognitive Skills:** The indexer calls various Azure AI Services to generate new, enriched data fields. Common skills include:
  * OCR (Optical Character Recognition) to extract text from images and scanned documents.
  * Key Phrase Extraction to identify the main topics.
  * Entity Recognition to detect people, locations, and organizations.
  * Language Detection and Translation.
  * Image Captioning and Analysis.
    
* **Vectorization:** A key enrichment is creating vector embeddings from the text, which is necessary for vector and hybrid search.

* **Knowledge Store:** The output of this enrichment process can be persisted in an Azure Storage or Cosmos DB account, creating a Knowledge Store for deeper analysis or visualization outside the search index.

**Phase 3: Explore**

The enriched and indexed data is then made available for consumption.

* **Search Applications:** Users interact with the data via a custom-built web or mobile application, using the sophisticated query capabilities of Azure AI Search.
* **Bots and AI Agents:** The search service provides the context for chatbots and AI assistants to answer user questions about the enterprise data (RAG pattern).
* **Data Analysis:** The Knowledge Store allows business analysts to use tools like Power BI to visualize and analyze the extracted entities and insights at scale.
